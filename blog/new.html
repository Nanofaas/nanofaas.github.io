New post

Fill in the fields, then open GitHub's editor with the post file ready in _posts/. Write the body in Markdown there and commit. A commit to main publishes the post within a few minutes; pick “Create a new branch” in the commit dialog to open a pull request instead. Without write access to the repository, GitHub offers to fork it and open a pull request.
